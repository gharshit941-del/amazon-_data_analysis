# 🛒 Amazon Sales Analysis Dashboard – Power BI

An interactive **Amazon Sales Analysis Dashboard** built using **Microsoft Power BI** to analyze sales performance, product categories, and key business metrics.

## 📊 Project Overview

This project focuses on transforming Amazon sales data into an interactive business intelligence dashboard.

The dashboard provides a visual way to explore sales information and identify patterns across different product categories and sales options.

## 🎯 Objectives

- Analyze Amazon sales performance
- Understand product/category-level trends
- Create interactive dashboards using Power BI
- Build meaningful KPIs and visualizations
- Enable filtering and interactive data exploration
- Convert raw business data into actionable insights

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Visualization**
- **Data Modeling**
- **Business Intelligence**

## 📈 Dashboard Features

The dashboard includes:

- 📊 Sales analysis
- 🛍️ Product/category analysis
- 🔎 Interactive filters and slicers
- 📌 KPI-style visualizations
- 📉 Comparative analysis
- 📋 Detailed data views
- 🎨 Interactive Power BI dashboard design

## 🗂️ Data Model

The Power BI project contains multiple data tables, including:

- `Amazon`
- `amazon-fashion - YT`
- `Sale_Option`

These tables are used to support the dashboard's analysis and visualizations.
